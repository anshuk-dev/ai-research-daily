### 1. cmHC: Balancing Stream Mixing in Hyper-Connections via Geometric Contraction
**🏛️ Source:** `arXiv / Hugging Face (65 upvotes)` &bull; **🏷️ Pillar:** `AI Systems & Infrastructure`

> **The Crux (Simple English):**  
> Manifold-constrained Hyper-Connections (mHC) extends residual connections to multiple streams and stabilizes residual propagation by constraining stream-mixing residual matrices to the Birkhoff polytope, the set of doubly stochastic matrices. In this work, we investigate how to effectively mix residual streams within the Birkhoff polytope.

**Key Takeaways & Paradigm Shift:**
  - 💡 **Core Innovation:** Motivated by these findings, we propose Contraction for Manifold-Constrained Hyper-Connections (cmHC), an exact doubly stochastic method which geometrically contracts the Birkhoff polytope toward its interior.
  - 📊 **Key Results:** Manifold-constrained Hyper-Connections (mHC) extends residual connections to multiple streams and stabilizes residual propagation by constraining stream-mixing residual matrices to the Birkhoff polytope, the set of doubly stochastic matrices.
  - 🚀 **Paradigm Shift:** Extensive experiments across dense and mixture-of-experts models at various parameter scales demonstrate the effectiveness and scalability of cmHC.

### 3. Clover-35B-A3B-Preview Technical Report
**🏛️ Source:** `arXiv / Hugging Face (33 upvotes)` &bull; **🏷️ Pillar:** `Autonomous Agents & Self-Improvement`

> **The Crux (Simple English):**  
> We introduce Clover-35B-A3B-Preview (Clover), a mixture-of-experts diffusion language model with 35 billion total parameters and 3 billion activated parameters, supporting thinking-mode generation. Clover adapts Gated Delta Networks to block diffusion by combining recurrent memory of previously generated context with bidirectional softmax attention inside the current block.

**Key Takeaways & Paradigm Shift:**
  - 💡 **Core Innovation:** We introduce Clover-35B-A3B-Preview (Clover), a mixture-of-experts diffusion language model with 35 billion total parameters and 3 billion activated parameters, supporting thinking-mode generation.
  - 📊 **Key Results:** We introduce Clover-35B-A3B-Preview (Clover), a mixture-of-experts diffusion language model with 35 billion total parameters and 3 billion activated parameters, supporting thinking-mode generation.
  - 🚀 **Why It Matters:** On an internal set of 500 groups, joint prediction raises question accuracy from 90.37% to 93.88% and all-correct group accuracy from 65.4% to 77.0%.
